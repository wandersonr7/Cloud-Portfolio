# Hands-on Labs

Use this folder for reproducible technical exercises completed outside graded coursework.

Each lab should have its own folder and README:

```text
labs/
  001-lab-name/
    README.md
    diagrams/
    scripts/
    screenshots/
```

Start with small local labs involving Linux, networking, Git, scripting, and containers. Add AWS labs only after the AWS account is intentionally created.

Use the [lab report template](../templates/lab-report-template.md) for consistent documentation.
