# Portfolio Projects

This folder will contain complete projects that demonstrate practical cloud and infrastructure skills.

| Project | Skills demonstrated | Status |
| --- | --- | --- |
| First project to be selected | Git, documentation, Linux or networking | Planned |

A portfolio project should include:

- A clear business or technical problem
- An architecture diagram when useful
- Reproducible setup instructions
- Testing or validation evidence
- Security and cost considerations
- Cleanup instructions
- A short lessons-learned section
