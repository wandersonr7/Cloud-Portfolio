- Linux and command-line fundamentals
- Networking and cloud concepts
- Git and GitHub workflow
- Scripting and automation

- Northwest Vista College coursework and independent practice

## Repository structure

| Area | Purpose |
| --- | --- |
| `nvc-coursework/` | Eligible coursework, notes, and projects from NVC |
| `labs/` | Reproducible hands-on lab documentation |
| `projects/` | Complete portfolio projects |
| `docs/` | Learning roadmap and supporting documentation |
| `templates/` | Reusable templates for documenting work |

## Current status

The AWS account is intentionally deferred until an NVC class or project requires it, preserving the new-account Free Plan period. AWS projects will be added later.

## Documentation standard

Each lab or project should explain:

1. The problem or learning objective
2. The architecture and tools used
3. Implementation steps
4. Validation and test results
5. Security and cost considerations
6. Resource cleanup
7. Lessons learned
