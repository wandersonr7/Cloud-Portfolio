# NVC Coursework

This folder is for portfolio-eligible coursework, notes, and projects completed at Northwest Vista College.

## Academic integrity

- Do not publish exams, quizzes, answer keys, or restricted assignment solutions.
- Follow each instructor's rules before uploading graded work.
- Rewrite project documentation in your own words.
- Remove student IDs, grades, instructor contact information, and classmate data.

## Suggested organization

Create one folder per course or major project:

```text
nvc-coursework/
  course-code/
    project-name/
      README.md
      src/
      diagrams/
      screenshots/
```

Every project README should identify the objective, individual contribution, technologies, validation steps, and lessons learned.
