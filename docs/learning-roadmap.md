# Cloud Learning Roadmap

## Phase 1 — Foundations

- Git and GitHub workflow
- Linux command line and permissions
- Networking fundamentals
- Basic scripting
- Clear technical documentation

## Phase 2 — Local hands-on practice

- Build small repeatable labs
- Document commands and results
- Add diagrams and redacted screenshots
- Practice troubleshooting and cleanup

## Phase 3 — AWS when required

Create the AWS Free Plan account only when an NVC class or portfolio project requires it.

Initial AWS setup checklist:

- Enable MFA for the root user
- Avoid root access keys
- Configure cost visibility and a small budget alert
- Use least-privilege identities
- Tag every lab resource
- Delete resources immediately after each lab

## Phase 4 — Portfolio development

- Convert selected NVC work into professional case studies
- Publish independent cloud projects
- Review the repository for secrets and personal data
- Make the repository public only when it is ready for employers
